📡 VLAN + DHCP Network Lab
🧠 Project Overview

This project simulates a small business network using VLAN segmentation, inter-VLAN routing, and DHCP automation. The goal was to design and configure a scalable and secure enterprise-style network.

🧰 Tools Used
Cisco Packet Tracer
Cisco Router (2911)
Cisco Switch (2960)

🏗️ Network Design
VLAN 10: HR Department (192.168.10.0/24)
VLAN 20: Accounting Department (192.168.20.0/24)
Router-on-a-Stick used for inter-VLAN routing
DHCP configured for automatic IP assignment

⚙️ Features Implemented
VLAN segmentation
Trunk port configuration
Inter-VLAN routing
DHCP configuration on router
Default gateway setup
Network testing with ping

📊 Skills Demonstrated
Network design
VLAN configuration
IP addressing
DHCP configuration
Troubleshooting connectivity issues

✅ Testing Results
Devices successfully received IP addresses via DHCP
Devices within VLANs communicated correctly
Inter-VLAN routing verified with ping tests
